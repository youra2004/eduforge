# ADR-0009: AI tutor

- The tutor prompt is built from an allow-list: the question text and options (`toStudentQuestion`), the student's own answer, the chat so far and chunks from `retrieve` over `allowedNodeIds` (the node + passed prerequisites). The guard is a separate call and is the only one that sees the reference answer, because it cannot judge "was the solution revealed" without it; it returns a verdict, never text. It fails closed: a guard error shows a static hint.
- Hint level is chosen by the server (one step up per request, max 3). A blocked reply is retried once one level lower, then replaced by the author's static hint (question → node → generic text). Static hints are authored in the course JSON (`nodes[].hints`) and copied into new versions.
- Help is closed while a node test of that node (or any exam) is running, so the tutor cannot answer a test in progress. Limits come from the log, not memory: `TUTOR_RATE_PER_MINUTE` messages per minute and `TUTOR_DAILY_TOKEN_BUDGET` tokens per rolling 24 h (tutor and guard calls both carry the session as subject in `llm_runs`). The switch-off for the experiment's control condition belongs to M07, which owns `condition`.
